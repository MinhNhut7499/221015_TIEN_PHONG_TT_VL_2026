# Image Generation Prompts — Architecture-AI Dataset

100 prompts for generating photorealistic architectural images covering all style families in `chatbot/knowledge/styles.json`.
Each prompt specifies 1 dominant style (5 features) + 5 secondary accent styles (1 feature each).

Companion ground-truth table: `docs/image_gen_ground_truth.csv`
